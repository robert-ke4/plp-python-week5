# Python Week 5 Project

This repository contains solutions and modular scripts developed as part of the Python Week 5 programming assignments. The projects focus on string manipulation, random module integration, function definitions, and structuring custom Python modules with proper execution control.

---

## Project Structure

| File Name | Description |
| :--- | :--- |
| `password_generator.py` | Generates random secure passwords of customizable lengths using Python's built-in `random` and `string` modules. |
| `helpers.py` | A custom module housing utility functions such as `tables_needed()` (using `math.ceil`) and `welcome()`. |
| `main.py` | An execution script that imports `helpers.py` to test and demonstrate the custom module functions. |

---

### Prerequisites
